My Journey Into Web Development

Written by Julius Othiambo

Published on September 26, 2026

How I Started

My journey into web development started with curiosity about how websites are created. I wanted to understand how a simple idea could become an interactive website that people can access from their phones and computers.

I started by learning HTML because it provides the basic structure of a webpage. Through practice, I learned how headings, paragraphs, links, images and forms work together.

Learning HTML

HTML has taught me that good websites need clear structure. I have also learned about semantic HTML elements such as <header>, <nav>, <main> and <footer>.

I am also learning about accessibility and why websites should be usable by as many people as possible.

Learning Git and GitHub

GitHub has become an important part of my learning journey. I am learning how to create repositories, create files, commit changes and organize my projects.

Keeping my projects on GitHub also gives me a place where I can build a developer portfolio and show my progress.

My Future Goals

My goal is to continue learning CSS and JavaScript and eventually develop complete websites and applications.

I also want to work on real-world projects that help me improve my problem-solving skills and become a better developer.
